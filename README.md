# clockcheck

**An honest audit harness for epigenetic aging clocks.**

Aging clocks return a single confident number — a predicted age, or an "age
acceleration" that gets correlated with every disease under the sun. The original
papers report that number under near-ideal conditions and quietly leave out what
happens when you reuse the clock on *your* dataset: missing probes, undisclosed
imputation, platform shifts, regression-to-the-mean, and clocks that flatly
disagree with each other about who is old.

`clockcheck` runs those left-out checks and prints a caveats-first **audit card**
for a `(clock, dataset)` pair. It leads with what could make the number wrong,
not with the number.

> Design rule, enforced in code: **we never fabricate weights or pass synthetic
> plumbing off as evidence.** Clock coefficients are read from published sources.
> The one synthetic generator in the codebase warns every time it runs and stamps
> its output `NON-EVIDENTIAL`.

## Install

```bash
pip install -e .            # core: numpy + pandas
pip install -e ".[real]"    # + biolearn: real published clocks & GEO loaders (recommended)
pip install -e ".[dev]"     # + pytest
```

`biolearn` supplies the published coefficient files (Horvath, Hannum, PhenoAge,
DunedinPACE, …) and real GEO data loaders. Without it, point `clockcheck` at your
own directory of `CpG,weight` CSVs via `CLOCKCHECK_COEF_DIR`.

## 60-second start

```bash
clockcheck list                 # show built-in clocks
clockcheck demo                 # full pipeline on a LABELED SYNTHETIC fixture (offline)
```

Real audit on a GEO series (needs `biolearn` + network):

```bash
clockcheck audit --clock Horvath1 --geo GSE40279 --compare Hannum PhenoAge --out card.md
```

Real audit on your own files:

```bash
clockcheck audit --clock PhenoAge --betas betas.csv --meta meta.csv --age-col age
```

`betas.csv` is a CpG × sample matrix; `meta.csv` is sample × fields including an
age column. Orientation is auto-detected.

In Python:

```python
from clockcheck import LinearClock, load_geo, build_audit_card, card_to_markdown

clock = LinearClock.load("Horvath1")
ds = load_geo("GSE40279")                       # real data
card = build_audit_card(clock, ds, compare_clocks=[LinearClock.load("Hannum")])
print(card_to_markdown(card))
```

## What the audits actually check

- **CpG coverage — weight-weighted.** Not "what % of probes are present" but "what
  % of the clock's total weight survives." A clock can be 97% covered and still be
  missing the probe that carries most of the prediction. That second number is the
  one papers never show; clockcheck puts it first.
- **Imputation sensitivity.** Re-runs the clock under `drop` / `mean` / `zero`
  rules for absent CpGs and reports how far each sample's predicted age swings.
  The imputation rule is usually undisclosed and can move a person by years.
- **Calibration vs chronological age.** Bias binned by age, plus the bias-vs-age
  slope. A slope near −1 is the regression-to-the-mean signature: the clock drags
  the old young and the young old, inflating associations at cohort extremes.
- **Age-acceleration fragility.** The residual everyone correlates with disease,
  computed under two equally defensible definitions. If they disagree, so will the
  downstream findings built on them.
- **Cross-clock agreement.** Run several clocks on the same samples; report the
  per-sample spread and Spearman correlation. Large disagreement undercuts the idea
  of one "biological age."

## Why synthetic data is quarantined

This project grew out of taking apart an aging-biomarker demo whose "validation"
ran on synthetic data through a circular fitting loop. So here, synthetic data
exists only to exercise the plumbing, is generated by a single loudly-named
function, and is stamped `NON-EVIDENTIAL` on every card it touches. A clean audit
card is **necessary, not sufficient** — it describes reliability, never truth.
